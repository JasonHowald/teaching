7 Technical definition, for the record

Technically, normal is not just unimodal, symmetric, unskewed, and bell shaped. A normal distribution fits the specific formula below. Lucky for us, we don’t need to use or memorize the formula in Math 125!

\[f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x - \mu)^2}{2\sigma^2}}\]

8 Central Limit Theorem

8.1 When should we expect a distribution to be normal?

If a data variable aggregates many small independent effects, it’s usually normal or close. For example:

  • Human height (arguably)
  • Exam scores (usually)
  • Cholesterol levels (usually)
  • Game scores in sports (basketball more than hockey!)
  • Sampling distributions (This is foreshadowing. More on this later!)

This phenomenon is called the Central Limit Theorem. Its precise statement is too technical for Math 125.

10 The empirical rule (68-95-99.7)

  1. Within one standard deviation from the mean lies 68% of the data.
  2. Within two standard deviations from the mean lies 95%.
  3. Within three standard deviations from the mean lies 99.7% …approximately.

11 The empirical rule (68-95-99.7)

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

# Parameters for the normal distribution
mu = 0  # Mean
sigma = 1  # Standard deviation

# Generate data for the normal distribution curve
x = np.linspace(mu - 4*sigma, mu + 4*sigma, 500)
y = norm.pdf(x, mu, sigma)

# Calculate exact percentages using CDF
percent_1std = (norm.cdf(sigma) - norm.cdf(-sigma)) * 100
percent_2std = (norm.cdf(2*sigma) - norm.cdf(-2*sigma)) * 100
percent_3std = (norm.cdf(3*sigma) - norm.cdf(-3*sigma)) * 100

# Create the plot
fig, ax = plt.subplots(figsize=(10, 6))
ax.plot(x, y, color='blue', linewidth=2, label='Normal Distribution PDF')

# Mark the mean
ax.axvline(mu, color='black', linestyle='--', label=r'Mean ($\mu$) = {mu:.2f}')

# Define the standard deviation ranges
std1_left, std1_right = mu - sigma, mu + sigma
std2_left, std2_right = mu - 2*sigma, mu + 2*sigma
std3_left, std3_right = mu - 3*sigma, mu + 3*sigma

# Shade the areas for 68%, 95%, and 99.7%
# 99.7% (3 standard deviations)
x_fill_3std = x[(x >= std3_left) & (x <= std3_right)]
y_fill_3std = y[(x >= std3_left) & (x <= std3_right)]
ax.fill_between(x_fill_3std, 0, y_fill_3std, color='purple', alpha=0.1, label=f'$\mu \pm 3\sigma$ ({percent_3std:.2f}%)')

# 95% (2 standard deviations)
x_fill_2std = x[(x >= std2_left) & (x <= std2_right)]
y_fill_2std = y[(x >= std2_left) & (x <= std2_right)]
ax.fill_between(x_fill_2std, 0, y_fill_2std, color='green', alpha=0.2, label=f'$\mu \pm 2\sigma$ ({percent_2std:.2f}%)')

# 68% (1 standard deviation)
x_fill_1std = x[(x >= std1_left) & (x <= std1_right)]
y_fill_1std = y[(x >= std1_left) & (x <= std1_right)]
ax.fill_between(x_fill_1std, 0, y_fill_1std, color='red', alpha=0.3, label=f'$\mu \pm 1\sigma$ ({percent_1std:.2f}%)')

# Add labels for standard deviation marks
plt.text(mu + sigma, norm.pdf(mu + sigma, mu, sigma) + 0.02, r'$\mu + \sigma$', horizontalalignment='center', color='red')
plt.text(mu - sigma, norm.pdf(mu - sigma, mu, sigma) + 0.02, r'$\mu - \sigma$', horizontalalignment='center', color='red')
plt.text(mu + 2*sigma, norm.pdf(mu + 2*sigma, mu, sigma) + 0.02, r'$\mu + 2\sigma$', horizontalalignment='center', color='green')
plt.text(mu - 2*sigma, norm.pdf(mu - 2*sigma, mu, sigma) + 0.02, r'$\mu - 2\sigma$', horizontalalignment='center', color='green')
plt.text(mu + 3*sigma, norm.pdf(mu + 3*sigma, mu, sigma) + 0.02, r'$\mu + 3\sigma$', horizontalalignment='center', color='purple')
plt.text(mu - 3*sigma, norm.pdf(mu - 3*sigma, mu, sigma) + 0.02, r'$\mu - 3\sigma$', horizontalalignment='center', color='purple')

# Set title and labels
ax.set_title('Empirical Rule (68-95-99.7) Illustration', fontsize=16)
ax.set_xlabel('Standard Deviations above/below the mean', fontsize=12)
ax.set_ylabel('Probability Density', fontsize=12)
ax.legend(loc='upper right')
ax.grid(True, linestyle='--', alpha=0.6)
plt.tight_layout()
plt.show()

17 A fair rating – data in context

Judge relative to average – subtract \(\mu\).

Judge relative to variability – divide by \(\sigma\).

\[\text{Z-score} = \frac{\text{data value} - \mu}{\sigma}\]

Z-score = number of standard deviations from the mean.

Z-score is an interchangeable standard of unusualness, scaled to the distribution the data belongs to.

18 Intuition for Z-scores

It counts the number of standard deviations from the mean, which is a statistically “fair” across different distributions.

  • Z = 0: Average.
  • Z = +1, -1: Uninteresting.
  • Z = +2, -2: Raise eyebrow.
  • Z = +3, -3: Remarkable.
  • Z = +5, -5: Stunning.

19 Practice with Z score

  1. A distribution for test scores is normally distributed \(N(500, 50^2)\). You score 625. Well done! What is your Z score?
  2. An LED manufacture process produces units with illumination \(N(50,0.2^2)\). One particular bulb has illumination 49.4.
  • What is its Z-score?
  • If we reject any bulb at 49.4 or below, how much of the inventory would we waste?
  • By reconfiguring the assembly process, we can make the distribution \(N(51, 1^2)\). How would you describe the effect of this change? How would this affect the manufacturing waste?

20 The rarity of a Z-score: the p-value

A good measure of the unusualness of a Z-score is the portion of the curve at least as extreme as that score, called the \(p\)-value.

21 Putting it all together

  1. Most people tend to score about 550 on a given exam, with a standard deviation of 60. Your score is 685. Good job! What is your Z-score? What is your percentile?
  2. An average business day sees about $1000 in sales, with a standard deviation of about $200. Sales were slow today. Only $450. What is the Z-score? How rare is such a disastrous sales day?
  3. A 1000-letter sample of English language should have on average about 80 “a”’s, with a standard deviation of about 9. A randomly chosen Youtube video description has 1000 characters but 120 “a”’s. What is the Z-score of this result? How rare is it? Can you think of alternate explanations?
