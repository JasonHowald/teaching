Review – two multiplication rules

Multiplication rule – simplistic

(works when \(A\) and \(B\) are independent) \[ P(A \text{ and } B) = P(A)*P(B)\]

Multiplication rule – full

(just works) \[ P(A \text{ and } B) = P(A)*P(B | A)\]

\[P(\text{drawing two aces}) = \frac{4}{52} \cdot \frac{3}{51}\]

\(P(B | A)\) “Probably of B given A” is a conditional probability. It’s the probability of \(B\), adjusted for condition that \(A\) is known.

Examples of conditional probability

U = You are using an umbrella.

R = It’s raining.

P(U) asks “How likely are you to use an umbrella, at any time?”

P(U | R) asks “When it’s raining, how likely are you to use an umbrella?”

P(R | U) asks “You’re using an umbrella. What’s the probability of rain?”

Solving for P(B|A)

\[ P(A\text{ and } B) = P(A) * P(B | A)\]

can be converted to

\[P(B|A) = \frac{P(A\text{ and } B)}{P(A)}\]

Depending on which two we know, we may use them to calculate the third.

Reversing a conditional – the accuracy paradox

A rare genetic disorder affects about 1/1000 of the population. You can test for it with a test which is 99% accurate. If a patient tests positive, how likely is it that they have the disorder?

Outline diagrams for managing cases and their probabilities

  1. Have the gene (1/1000)

    • test negative (1/100)
      • p = .00001
  2. Lack the gene 999/1000
    • test positive (1/100)
      • p = .00999
